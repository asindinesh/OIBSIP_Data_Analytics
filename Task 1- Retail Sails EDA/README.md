## Retail Sales Data Analysis

# Objective

Perform Exploratory Data Analysis (EDA) on a retail sales dataset to identify customer purchasing behavior, sales trends, and business insights using Python.

## Technologies Used

Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

## Features
Data Loading and Inspection
Descriptive Statistics
Monthly Sales Trend Analysis
Quarterly Sales Trend Analysis
Customer Age Distribution
Gender Breakdown
Revenue by Product Category
Correlation Heatmap

## Additional Data Visualization
Business Recommendations
Dataset
Retail Sales Dataset

## Outcome
This project analyzes retail sales data to understand customer behavior, identify sales patterns, and provide actionable business recommendations.
